= Installation process
:page-pagination:

== Options

* `--bash` Install autocompletion for bash
* `--zsh` Install autocompletion for zsh

CAUTION: The options below are for testing and debug purposes. You should not use them unless your OS does not follow FHS.

* `--install-dir <dir>` Set the location where all scripts will be installed (default: `/usr/local/bin`)
* `--conf-dir <dir>` Set the location where all configuration files will be installed (default: `/etc/fenrir`)
* `--man-dir <dir>` Set the location where man pages will be installed (default: `/usr/share/man`)
* `-t` Test mode. Warning messages are muted and non-sudo execution is allowed
* `--debug` Debug mode. Build artifacts are not removed after the installation
* `--env <file>` Initial values for `lokirc` file

== Assembling installation script

IMPORTANT: Build directory is `/tmp/FENRIR_BUILD`

File https://github.com/1BAH/fenrir/blob/main/src/main/fenrir/cli/install-fenrir[`install-fenrir`] assembles the installation script and saves it to `/tmp/FENRIR_BUILD_SCRIPT`. It contains subscripts:

* `install-fenrir` (main script)
* `install-loki` (loki module installation)
* `inline-funs` (inlining stage)

=== Installing loki

`loki` is a custom interpreter for the project. It is `bash` with predefined environment and signal handlers.

File https://github.com/1BAH/fenrir/blob/main/src/main/fenrir/cli/install/install-loki[`install.loki`] assembles the interpreter. It is produced by inlining `#include` directives in `loki`.

. `loki-common-funs` is assembled into `/tmp/FENRIR_BUILD/loki/LOKI_COMMON_FUNS_ASM` (scripts from `funs` are inlined)
. `loki-common-*` and `loki` are merged into `/tmp/FENRIR_BUILD/loki/LOKI_ASSEMBLED`
. The resulting file is copied to _install-dir_

=== Inlining functions

The scripts in `fenrir/core/inline` are inlined into the scripts in `fenrir/core` according to `#include` directives

=== Installing fenrir

. Check for superuser permissions
. Check for autocompletion preferences
. Check for requirements
. Assembling installer
. Running installer
.. Verify sources structure
.. Load configs from `fenrir.properties`
.. Create build directory
.. Verify build directory
.. Install loki
.. Switch to loki from bash
.. Inline functions
.. Determine user
.. Determine OS
.. Check filesystem for previous installations and conflicting apps
.. Install files
.. Install config
.. Setup `FENRIR_HOME`
.. Install autocompletion
.. Remove build artefacts

== Errors

When assembling the installation script::

* `111` -- Non-privileged execution without `-t` option
* `121` -- `install-dir` does not exist
* `122` -- `conf-dir` does not exist
* `123` -- `man-dir` does not exist
* `130` -- `gsed` is not install when system `sed` is a BSD version
* `140` -- unsatisfied requirements
* `141` -- `bash` is outdated

When running the installation script::
* `5` -- `$VERSION` was not set (see `fenrir.properties`)
* `6` -- Unsupported OS
* `7` -- Commands are already present
* `8` -- Cannot find `asciidoctor` to compile man pages
// verify-src
* `11` -- `$CLI_DIR` does not point to `cli`
* `12` -- `$FENRIR_DIR` does not point to `fenrir`
* `13` -- `$LOKI_DIR` does not point to `loki`
* `14` -- `$DOC_DIR` does not point to `doc`
// verify-build
* `15` -- `$CORE_UTILS_DIR` does not point to `core`
* `16` -- `$CFGS_DIR` does not point to `configs`
* `17` -- `$BASIC_UTILS_DIR` does not point to `shared`

* `20` -- Failed to create `lokirc` file
* `21` -- Failed to install a script
* `22` -- Failed to install a config file
* `23` -- Failed to install `lokirc` from a provided env file

* `24` -- Failed to create the local repository
* `25` -- Failed to install configs to the local repository
