== Why fenrir?

Minimal dependency list::
The project is written entirely in `bash`, using only `sed` and `curl` utilities.

Multiplatform::
Since it is written in `bash`, you can run `fenrir` on Linux (amd & arm) or on macOS.

Container oriented::
The tool is designed to use as less space as possible which makes it perfect for containers.

Not bound to any programming language::
Single interface which allows you to test different languages, tools (e.g. see https://devtools-course.github.io[DevTools course]).

Shell scripts ass tests::
Concise syntax when dealing with IO and extra utils, provided by the framework.

Integrated dev environments::
Having provided a dev environment (container), you can enter it and develop.

Grading::
When running tests, `fenrir` calculates a score based on the predefined points.

Integrated shell execution tracing::
All commands are traced and the whole trace is printed when an error occurs.
