= Fenrir's changelog

== Version 2026.1.5
* Now envs have shared folder: `/tmp/fenrir-shared` is mounted to the `fenrir-shared` volume (recreated each env creation)
* Unified text emoji api
* Reformat `fenrir info` output
* Option `inlined` for inline execution in docker (ignored when `rund`)

== Version 2026.1.4
* Minor fixes with FEND (make it run inside gitlab ci)

== Version 2026.1.3
* Finalise API
* Fix rpm bug (disable shebang mangling)
* Fix releases in gh

== Version 2026.1.2
* `fenrir-cont-run` prints `docker run` output
* Added `fenrir-main-cont`: prints main container ID
* When in dev env `FENRIR_IN_ENV` is non-empty

== Version 2026.1.1
* Extract tracing logic to `jotunheim` file
* Now support `global.init` & `global.destroy` scripts
* Add `-y` option for installer
* Other runtime bugs
* Renamed `loki-assert-rnegeq` -> `loki-assert-regneq`
* Add `docker run` wrapper

== Version 2026.1
* Switch to `fenrir-get-_` path resolvers

== Version 2026.0

* Switched from semver to https://calver.org/[calver]
* `pre` block in pipeline is removed
* Supported `env` subcommand (create & manage a dev env)
* Supported fixtures
* Added man pages
* Supported `deb` & `rpm` distribution
* Updated autocomplete
* Minor refactoring
